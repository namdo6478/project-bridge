# 축산기계장터 개발 로드맵

## 제품 목표

전국의 축산 농가와 장비 판매자를 연결해 중고·신품 장비를 찾고, 팔고, 구매 요청할 수 있는 신뢰 기반 장터를 만든다.

## 현재 구현 상태 — Sprint 1

- 반응형 공통 헤더, 홈, 매물 목록, 매물 상세
- 현장 기준 7개 대분류와 세부 품목 체계
- 검색어, 대분류, 세부 품목, 지역, 신품·중고, 가격순 필터
- 판매중·예약중·판매완료·구매요청 상태
- 12개 샘플 매물과 `삽니다` 예시
- 장비 사진, 정보, 가격, 지역, 연락처를 입력하는 `/sell` 화면
- 판매 등록 전 입력 내용 미리보기
- PC·태블릿·휴대폰 반응형 UI

## 진행 중 — Sprint 2 기반 작업

- Supabase 브라우저·서버 클라이언트와 세션 갱신 Proxy
- 사용자, 매물, 매물 사진, 관심 매물 데이터베이스 스키마
- 사용자 본인 데이터만 수정할 수 있는 RLS 정책
- 이메일 로그인·회원가입 화면과 인증 콜백
- 등록 폼의 서버 검증, 판매자 프로필 저장, 실제 매물 저장
- 데이터베이스 연결 전에는 기존 샘플 매물로 안전하게 동작하는 폴백

다음 연결 순서는 Supabase 프로젝트 생성 → 환경 변수 입력 → SQL 마이그레이션 적용 → 로그인·등록 실사용 검증 → 사진 업로드입니다.

## MVP 완료 기준 — Sprint 2~3

### Sprint 2: 실제 등록과 계정

1. 휴대폰 번호 또는 소셜 로그인
2. 사용자·매물 데이터베이스
3. 장비 사진 업로드와 대표 이미지 지정
4. 매물 등록·수정·삭제
5. 내 매물과 관심 매물
6. 판매 상태 변경

### Sprint 3: 문의와 운영 안전

1. 판매자 연락 또는 안전 문의 기능
2. 신고·차단과 운영자 검수
3. 판매자 본인 확인 표시
4. 허위 매물·선입금 사기 예방 안내
5. 관리자 매물·회원 관리 화면
6. 기본 이용약관·개인정보 처리방침

## MVP 이후 확장

### 거래 활성화

- 새 매물·가격 변동 알림
- 지역 거리순 검색과 지도
- 제조사·모델·연식별 상세 검색
- 장비 비교와 최근 본 매물
- 구매 희망 글에 판매자가 제안하는 역매칭

### 사업 확장

- 신품 판매점 전용관과 판매자 구독
- 상단 노출·추천 매물 광고
- 운송·정비·검사 파트너 연계
- 장비 시세 데이터와 적정 가격 안내
- 안전결제 또는 계약금 보호 기능 검토

## 개발 우선순위 원칙

1. 매물 탐색과 등록을 먼저 완성한다.
2. 개인정보와 결제가 포함되기 전 인증·권한·신고 기능을 갖춘다.
3. 실제 사용자 행동을 확인한 뒤 알림, 지도, 결제 기능을 확장한다.
4. 새로운 아이디어는 백로그에 추가하고 진행 중인 Sprint 범위를 흔들지 않는다.
